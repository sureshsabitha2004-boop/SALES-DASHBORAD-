📊 Excel Sales Dashboard – Data Analysis Project

📌 Project Overview

This project is an interactive Sales Dashboard created using Microsoft Excel to analyze and visualize sales performance across different products, regions, and salespersons.

The dashboard provides a clear overview of important business metrics, helping users understand sales trends, product performance, regional contributions, and overall profitability.

🎯 Project Objectives

Analyze overall sales performance.

Track total sales and average sales.

Monitor the total number of units sold.

Analyze profit generated from sales.

Compare sales performance across different products.

Identify regional sales performance.

Evaluate individual salesperson performance.

📈 Dashboard Features

1. Key Performance Indicators (KPIs)

Total Sales

Average Sales

Units Sold

Total Profit

2. Data Visualization

Units Sold by Product – Line Chart

Total Sales by Region – Doughnut Chart

Total Sales by Product – Bar Chart

Total Sales by Salesperson – Column Chart

3. Interactive Filters

Product-wise filtering

Salesperson-wise filtering

Interactive dashboard analysis
